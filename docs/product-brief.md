# Narrate

Audience: makers and educators explaining a real tool to multilingual audiences.
Promise: record your voice, choose languages, and make screen-led explanations
with local voice generation, captions, provenance and playback review.

Standalone project at narrate.humanquest.net, separate from Walkthrough Studio.
The owner chose Narrate, authorized the cloned voice for public examples, and
asked us to select between logo directions 03 and 04. Direction 03 is selected.

Website: functional language/model explorer, ten narrated review films with
sources and captions, actual studio screenshots, a studio helper film and a
portable skill ZIP. Public pages do not access microphone audio or private APIs;
recording and inference run in the installed local skill.

The first collection follows 2026 total speakers (L1 + L2): English, Mandarin,
Hindi, Spanish, Modern Standard Arabic, French, Bengali, Portuguese, Indonesian
and Urdu. Ranking source/methodology are linked in the gallery. Each language
spans many cultures. Each film is one audience-specific example, not a claim
about every speaker. Screen stills and review limitations are clearly identified.

MVP success: visitors understand the skill, choose languages and compare eligible
models, play real examples with captions, and download the same local studio
that produced them. No accounts, remote speech API, reference-audio uploads,
GitHub Actions or automatic Git deployment are introduced.
