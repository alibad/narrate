LOCAL SETUP / REVIEW BUILD

Your voice.
On your computer.

A coding-agent skill with a real microphone studio and local voice models.

Download the skill ZIP ↓

Start with your agent

Extract the archive. Add its narrate-video folder to your agent’s local skills location, following that agent’s installation instructions. For Claude Code that is ~/.claude/skills/narrate-video (on Windows, %USERPROFILE%\.claude\skills\narrate-video). The folder contains SKILL.md, scripts, references and local verification checks.

Then ask your agent to use the narrate-video skill and open the voice studio: /narrate-video in Claude Code, $narrate-video in Codex. The agent should read the bundled local setup guide, reuse a compatible environment or prepare an isolated one, and start the loopback server.

The browser flow

  1. Choose your narration languages.
  2. Review compatible cloning models and the recommendation.
  3. Download and verify the selected model.
  4. Record English once and choose Use this one. Other languages use it automatically unless they have a separate reference. Rehearse with the language example and Latin-letter guide; use your own natural voice. A new take changes only that language after Use this one.
  5. Generate and listen to auditions in every selected language before saving the profile.

What you need

The voice studio runs on an Apple Silicon Mac (Python 3.12 with MLX-Audio 0.5.1: OmniVoice, Chatterbox Multilingual and Qwen3-TTS Base), or on Windows or Linux with an NVIDIA GPU (CUDA PyTorch with chatterbox-tts: Chatterbox Multilingual). Both need FFmpeg. Core video rendering uses Python, Pillow and FFmpeg on any system. Model weights are separate downloads; no cloud API key is required. Other computers can use supplied audio with the renderer.

What remains yours

Recordings, transcripts, model weights and generated voice files stay in the private data folder selected by your agent. They are not bundled into the public skill. The website does not upload microphone audio or connect to a private voice service.

For developers

Run the bundled scripts/verify.sh locally before changing or redistributing the skill. Use the full bundled documentation for narration identity, language eligibility, source attribution and media review.
