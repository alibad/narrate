# Public-candidate boundary

This package is a local review candidate. No redistribution license is asserted.
Before publishing, establish ownership/redistribution rights for source material,
helpers, fonts, model output and any reference voices, then choose a license.
Removing identity markers does not establish those rights.

Review filenames, docs, metadata, URLs, environment variables, source, images,
video pixels, spoken audio and generated receipts. Keep source archives, private
assessments, credentials, browser state, reference recordings and product assets
outside a public package. Do not ship work-specific examples under neutral names.

The supplied example card is newly authored neutral HTML. No pre-recorded voice or product capture is bundled. The recording studio
is derived from the supplied source and requires redistribution rights review. Optional provider
and browser paths belong in production configuration, not the distributable skill.
