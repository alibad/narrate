# Narrate engineering

- Verify and build locally with `npm run build` and `npm run verify`.
- Run `skill/narrate-video/scripts/verify.sh` with the configured audio Python.
- Do not create or enable GitHub Actions without an explicit request.
- Deploy tested local output; do not enable automatic Git deployments.
- Preserve the language-first five-step studio flow and explicit model choice.
- Keep reference recordings, private transcripts, model weights and raw
  production under private storage. They do not belong in the source package.
- Public gallery films use the authorized creator voice and retain their source
  credits and review labels. A decoded file or ASR match is not listening approval.
- Show actual captured screens; distinguish stills, action clips and illustrations.
